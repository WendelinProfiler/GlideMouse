# Black Magic Mouse product model

Downloaded from the freely shared D5 model linked by brianfeyling:
https://forum.d5render.com/t/apple-devices-tech-free-3d-assets/36157

Public download: https://mega.nz/file/RtwyVDYK#_WaGQ9LdVrcXNIx9dx7N79Z9GZMa4er-wZZ8wDBhBN0

The post author states that these are conversions of Apple Store USDZ assets. That claim has not been independently verified against an original Apple-hosted USDZ. Do not describe this file as a verified official Apple download. The model predates the USB-C model and is not verified to have the USB-C underside.

Downloaded D5 archive SHA256: 74F709DF03F9743C2FE9AD245A1596848F733C334EBC05FCA6628B292A84F3BE

The original geometry was converted locally to Blender without remodelling the mouse. 25 mesh instances, 19,455 triangles, original material colors. D5 binary arrays are validated for bounds and triangle indices. Studio lighting and a 48-frame gentle rotation were rendered locally with Blender. No generated image, screenshot or screen recording was used.
